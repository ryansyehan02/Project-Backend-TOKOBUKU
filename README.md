# Project Backend TOKOBUKU

## Description
Project Backend **TOKOBUKU** adalah aplikasi backend berbasis **PHP & MySQL** yang digunakan untuk mengelola sistem toko buku, mulai dari data buku, administrator, hingga struktur database.

Project ini dibuat sebagai implementasi sistem backend sederhana untuk kebutuhan pembelajaran dan simulasi aplikasi toko buku.

## 🛠 Teknologi yang Digunakan

- **Bahasa Pemrograman**: PHP (Native)
- **Database**: MySQL
- **Server**: Apache (XAMPP / Laragon)
- **Tools Pendukung**:
  - phpMyAdmin
  - Visual Studio Code
  - Git & GitHub

## ✨ Fitur Utama

- Manajemen data buku
- Manajemen administrator
- Koneksi database MySQL
- Struktur backend terpisah (connection & master data)
- Import database langsung dari file `.sql`
- Dokumentasi alur data menggunakan PDM (Visual Paradigm)


## Installation
1. Clone repository
2. Setup environment (XAMPP & MySQL)
3. Run server
